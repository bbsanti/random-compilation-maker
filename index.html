    2. Parameters

    Each parallel encode is a separate FFmpeg instance, so more of them means more memory.

    Output keeps the source resolution, frame rate, field order, codec and file type. If the sources disagree on any of those, you'll be asked which format to render as and which mismatched clips to exclude. Audio is always removed; clips are re-encoded, so cuts are frame-accurate.
